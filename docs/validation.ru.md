# Проверки и границы подтверждённой работы

[English](validation.md) | **Русский**

Исходный код имеет статус прототипа. Его публикация не означает совместимость со всеми провайдерами или гарантированное ускорение сети.
Текущий интерфейс прошёл 15 приёмочных сценариев на изолированном сборочном Docker-стенде: группировка и раскрытие IP, сохранённые причины выбора, жизненный цикл и резервный режим настоящего ELK Worker, стабильность области просмотра при SSE, сбросы скорости и разрывы данных, медиана RTT, обрезка карточек, мобильная клавиатура и резервный режим, полноэкранный режим/Escape/меню, экспорт настроек клиентов и переподключение API воркера.
Компактные карточки проверены при 1920x1080 и 3592x1956; четыре строки IP помещаются по высоте при масштабе 100%.

Тяжёлые Go race/vet и проверки фронтенда выполняются на сборочном сервере с закреплёнными инструментами.
GitHub workflow выполняет только лёгкие проверки гигиены репозитория и синтаксиса Python.
Успешный CI не является новым тестом среды исполнения, UDP, безопасности или пропускной способности.

В репозитории недопустимы настоящие ссылки подписок, заголовки устройства/HWID, заполненные env-файлы, закрытые снимки стека, списки скачиваемых файлов и производственные скриншоты.
Скриншот карты в README использует синтетические адреса RFC5737 и тестовый воркер.

Архитектура среды исполнения ранее проходила одноразовые TCP/UDP и производственные проверки, но публикация кода не подтверждает заново доступность провайдеров и не доказывает производительность на настоящем ARM.
Эта версия не объединяет один TCP-поток через несколько прокси.

## Проверки первой публикации (2026-10-21)

- Закреплённый Go 1.27.2: `go test -race ./...` и `go vet ./...` прошли на сборочном сервере.
- Сборка TypeScript/Vite и 15 сценариев интерфейса прошли для выкаченного фронтенда.
- Gitleaks v8.30.1 не нашёл секретов в подготовленном публичном коде; проверки репозитория и синтаксиса Python прошли.
- Публичная конфигурация Compose успешно разрешилась. Новый изолированный стек с пустыми данными и ранее принятыми образами среды исполнения/фронтенда прошёл проверки UI/CSP/входа по паролю/топологии. Это проверка запуска Compose, а не новая пересборка всех образов или тест WAN.
- Выкатка только фронтенда сохранила идентичность воркера, control-plane и посторонних контейнеров; HTTP/SOCKS5 TCP в частной сети и HTTPS интерфейса работали.

Скриншот получен на синтетическом стенде и не используется для измерения скорости.
