# Сообщение об уязвимостях безопасности

[English](SECURITY.md) | **Русский**

Для приватного отчёта используйте функцию Security advisories / Report a
vulnerability в репозитории. Не публикуйте URL провайдеров, заголовки
HWID/устройств, пароли, приватные ключи, cookies, экспорты или производственные
дампы пакетов в issue.

Укажите затронутый коммит/версию, структуру конфигурации без секретов,
воспроизведение в одноразовой среде, влияние и ожидаемое поведение.
Гарантированный SLA ответа не обещается. Ограничения происхождения
зависимостей/версий и проверки безопасности описаны в docs/security.ru.md.
