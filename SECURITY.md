# Security reporting

**English** | [Русский](SECURITY.ru.md)

Use the repository Security advisories / Report a vulnerability feature for a
private report. Do not publish provider URLs, HWID/device headers, passwords,
private keys, cookies, exports or production packet captures in issues.

Include affected commit/version, configuration shape with secrets removed,
reproduction in a disposable environment, impact and expected behavior.
There is no promised response SLA. Dependency/version provenance and security
review limitations are described in docs/security.md.
